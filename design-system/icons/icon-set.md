# Icon Set

20px line icons used throughout the NexHealth platform. Based on a consistent 20x20 grid with 1.5px stroke weight.

## Icon Grid

- Canvas: 20x20px
- Stroke: 1.5px
- Corner radius: 2px (where applicable)
- Style: Outlined (not filled), rounded line caps

## Usage Guidelines

- Use `sm` (16px) for inline text and table cells
- Use `md` (20px) for buttons, navigation, and form fields
- Use `lg` (24px) for empty states and feature highlights
- Color inherits from parent text color by default
- Interactive icons use `neutral.500` idle, `primary.500` on hover
